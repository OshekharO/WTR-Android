# WTR Android

Flutter reader app for the WTR chapter API.

## Run

```bash
flutter pub get
flutter run
```

## Features

- Flutter Material 3 UI
- Dio API client
- Logger-based debugging
- Chapter request/response models
- Reader screen with glossary replacement support
- Android internet permission

## Endpoint

`POST https://wtr-lab.com/api/reader/get`
